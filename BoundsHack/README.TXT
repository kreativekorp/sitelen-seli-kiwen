This folder contains a version of sitelen seli kiwen with a hack to fix
line spacing in environments that use the bounding box of a font instead
of the typographical ascent and descent. Use this version if the line
spacing in your environment is way too large. Environments known to have
this issue include:

- Android (using sitelen seli kiwen as a system font)
- IbisPaintX
- some versions of some Adobe software
